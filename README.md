# MR.-HEART
🌸 MR. HEART — A Romantic Spring Experience ❤️

MR. HEART is a beautiful, interactive, spring-themed animated webpage created using HTML, CSS, and JavaScript. It presents a cinematic visual journey featuring flying birds, gentle rain, sunshine, a seven-color rainbow, drifting clouds, and falling spring flowers — ending with a romantic I LOVE YOU message.

✨ Features

- 🐦 Flying Birds: Birds fly from right to left across the sky.
- 🎵 Background Music: YouTube music integration.
- 🌧️ Rain Animation: Gentle animated rainfall.
- ☀️ Sunshine: A sun emerges behind the clouds with glowing rays.
- 🌈 Seven-Color Rainbow: A colorful rainbow appears after the rain.
- ☁️ Moving Clouds: Soft clouds drift across the sky.
- 🌸 Spring Effects: Falling flower bunches, cherry blossoms, petals, and leaves.
- ❤️ Romantic Message: Animated "I LOVE YOU" text with red and pink styling.
- ✍️ Creator Signature: "CODED BY HR. SANJU RAI".
- 📱 Responsive Design: Designed for mobile and desktop screens.

🎬 Animation Sequence

The experience follows a timed cinematic sequence:

1. Tap TAP TO BEGIN ♥.
2. Birds begin flying from right to left.
3. Background music starts.
4. Rain begins falling.
5. The sun emerges and sunlight rays appear.
6. A seven-color rainbow forms.
7. Clouds drift across the sky.
8. Spring flowers and petals begin falling.
9. The final I LOVE YOU message appears.

🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Locate "index.html".
4. Open it in a modern web browser.
5. Press TAP TO BEGIN ♥ to start the experience.
